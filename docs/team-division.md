# חלוקת עבודה ראשונית

החלוקה להלן היא טיוטה לפי סדר הרמה המקצועית שמסרתם. היא נותנת לאדם
החזק ביותר אחריות אינטגרציה, ומחלקת לכל חבר תחום שאפשר לבדוק ולהציג בנפרד.
כל חבר עדיין חייב להכיר את כלל המערכת.

| חבר/ה | בעלות ראשית | תוצרים ראשונים |
| --- | --- | --- |
| איתי | ארכיטקטורה ואינטגרציה | MVC, חוזי API, code review, מיזוג PRים ויציבות `main` |
| חיים | Backend ומסד נתונים | מודלי Mongoose, CRUD, חיפוש/סינון/מיון, pagination ו-seed |
| דור | חוויית משתמש ציבורית | עמוד הבית, כרטיסי כתבות, עמוד כתבה, AJAX, SEO ורספונסיביות |
| ברמר | הזדהות ו-workflow | login, session persistence, roles, אזור כתב ואזור עורך |
| לירי | יכולות רוחב ובדיקות | תגובות והגבלת ספאם, מזג אוויר, Impact Analytics, QA ותיעוד הדגמה |

## סדר ביצוע

### שלב 1 — תשתית משותפת

איתי מוביל את השלד. חיים מוודא שמודל הנתונים מתאים לדרישות. דור מכין
את רכיבי התצוגה. ברמר מגדיר את חוזה המשתמש וההרשאות. לירי מכינה מטריצת
בדיקות ותרחישי הגנה.

### שלב 2 — ליבה

חיים בונה CRUD לכתבות ולמשתמשים, דור מחבר את הפיד ל-AJAX, וברמר בונה
את מנגנון ה-session והרשאות השרת. איתי מבצע אינטגרציה בכל סוף שבוע.

### שלב 3 — תהליך עריכה

ברמר אחראי על מעברי המצבים, חיים על עקביות הגרסאות, דור על טפסי העריכה,
ולירי בודקת מקרי קצה והרשאות.

### שלב 4 — הרחבות והדגמה

לירי מחברת תגובות, מזג אוויר ואנליטיקות. חיים מריץ seed של 500 כתבות.
דור משלים נגישות ורספונסיביות. איתי מקפיא גרסת הגשה ומוביל חזרה מלאה
על תרחישי ההגנה.

## כלל עבודה חשוב

לפני merge כל חבר מסביר לחבר אחר את הקוד שלו בקצרה. פעם בשבוע עושים
סבב שבו כל אחד מציג שינוי של חבר אחר, כדי לעמוד בדרישה לשליטה בכלל הקוד.
